# 📌 Overview

The **Lab Booking System** is a full-stack web application that allows students and staff to easily reserve laboratory equipment while giving administrators full control over equipment management and booking monitoring.

It replaces manual booking processes with a secure, real-time digital platform that improves:

✔ Equipment tracking  
✔ Lab accessibility  
✔ Booking transparency  
✔ Administrative control  

---

# ✨ Key Features

## 👩‍🎓 Student Portal
- 🔎 Browse available lab equipment  
- 📅 Book equipment by date & time  
- 📊 Check real-time availability  
- 🧾 View booking history  
- 🔔 Prevent double-booking automatically  

---

## 🧑‍💼 Admin Dashboard
- ➕ Add / edit / delete equipment  
- 📋 View all bookings in the system  
- 📈 Monitor usage statistics  
- 👥 Manage users & permissions  
- 🚫 Block unavailable equipment  

---

## 🔐 Security & System Reliability
- 🔒 Firebase authentication  
- 👮 Role-based access control  
- ⏳ Automatic session timeout  
- ☁ Real-time Firestore database sync  
- 🛡 Input validation & protected routes
